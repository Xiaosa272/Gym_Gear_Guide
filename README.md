# Gym Gear Guide

A four-page English website for the Web Technologies personal project.

## Pages

- `index.html` — home page
- `equipment.html` — six equipment choices and filters
- `planner.html` — interactive training planner
- `safety.html` — simple gym rules

## Run it

Open the folder with VS Code and use Live Server. The site has no server, database, login or saved data.

## Before GitHub Pages

Replace `YOUR-GITHUB-NAME` in all four HTML files with the real GitHub user name. Then push this folder to its own public repository and enable GitHub Pages.
